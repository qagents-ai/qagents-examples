# Recorded offline outputs

These are actual results from running all 18 QAgents applications with their
explicit offline model fixtures. JSON and Markdown artifacts are retained with
[source/output hashes](../../research/sample-provenance.json).

Each report lists the artifacts produced during execution. SQLite databases are
created by the examples but are excluded from this snapshot. Run the collection
to inspect those destination queues, workflow journals, profiles and mailboxes.

The proposal is a fictional draft. Translation checks preserve placeholders and
glossary terms; they do not establish general translation quality. The individual
guides document the verifier's scope and the external services replaced by fixtures.
