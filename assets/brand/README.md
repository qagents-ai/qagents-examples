# QAgents visual identity

[examples-cover.svg](examples-cover.svg) is editable SVG source. It uses the journal Q mark from
[QAgents](https://github.com/qagents-ai/qagents/tree/main/assets/logo), indigo for
execution history and teal for the current state. The marks and lettering stay
consistent across the runtime, Gym and application examples.

Edit paths and text directly in the SVG or open it in a vector editor. Keep the
`title`, `desc` and view box so the image remains accessible and scales with the
page. Preview the result at README width and on a narrow screen. The image has
no scripts, remote fonts or external dependencies.
